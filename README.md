# Lista de Contatos

Projeto 5 da EBAC (módulo 32): lista de contatos feita com React, Redux Toolkit e Styled Components.

## Funcionalidades

- Adicionar contato (nome completo, e-mail e telefone)
- Editar contato direto na lista
- Remover contato

## Tecnologias

- React + Vite
- Redux Toolkit (`createSlice`, `configureStore`) com `useSelector` e `useDispatch`
- Styled Components (estilo global e estilos por componente)

## Como rodar

```bash
npm install
npm run dev
```
